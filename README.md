# Mid-term Nav Challenge

A small responsive front-end project built as a midterm navigation challenge. The site includes a mobile-friendly navigation bar and a few content pages styled with HTML, CSS, and JavaScript.

## Overview

This project demonstrates:

- A responsive top navigation bar
- Mobile menu behavior with a hamburger icon
- Multi-page site structure
- SASS-based styling workflow
- Lightweight static web design

## Project Structure

- `index.html` — home page
- `about.html` — about page
- `contact.html` — contact page
- `news.html` — news page
- `css/styles.css` — compiled stylesheet
- `scss/` — SASS source files
- `app/app.js` — navigation behavior script
- `images/` — project imagery

## Tech Stack

- HTML5
- CSS3
- Sass
- JavaScript
- Live Server (for local preview)

## Getting Started

1. Install dependencies:

   ```bash
   npm install
   ```

2. Start a local preview server:

   ```bash
   npm run live-server
   ```

3. Open the generated local URL in your browser.

## Optional Styling Workflow

If you want to recompile the Sass stylesheet while editing:

```bash
npm run compile-sass
```

## Notes

This project is designed as a static website and does not require a backend or database.
